## Requisitos del sistema

- Tener instalado el JDK 11 o una versión compatible con el proyecto.
- Disponer de IntelliJ IDEA o de una terminal con las herramientas de Java.

## Test

1. Descarga el repositorio desde GitHub mediante Code → Download ZIP y descomprime el archivo, o clónalo con Git.

2. Abre IntelliJ IDEA y selecciona File → Open.

3. Selecciona la carpeta raíz RoomServiceDev.

4. Comprueba que el proyecto tiene configurado el JDK 11.

5. Abre src/Main.java.

6. Pulsa el botón Run junto al método main() para compilar y ejecutar la aplicación.

Ejecutar desde la terminal

Desde la carpeta raíz del proyecto, compila los archivos Java:

```console
javac -d out src/*.java
```

Después, ejecuta la aplicación:

```console
java -cp out Main
```
Estos comandos suponen que las clases Java están directamente dentro de src/, no utilizan declaraciones package y no necesitan bibliotecas externas.

### Notas

La carpeta out/ contiene los archivos compilados y se genera localmente.

No es necesario descargar los archivos compilados desde GitHub.

Si el proyecto incorpora dependencias externas o cambia su estructura, estas instrucciones deberán actualizarse.
